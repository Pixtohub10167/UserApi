# UserApi

Лабораторная работа №2, часть 3.
Дисциплина: «Разработка кода информационных систем».

## Тема
Взаимодействие с базой данных по сети. REST API и формат JSON.

## Описание
Веб-сервис на ASP.NET Core 8, реализующий CRUD-операции над таблицей пользователей через REST API. Обмен данными — в формате JSON.

## Стек
- **Язык:** C# 12 / .NET 8
- **Фреймворк:** ASP.NET Core 8 Web API
- **ORM:** Entity Framework Core 8 (Code First)
- **СУБД:** SQLite
- **Документация:** Swagger (Swashbuckle)

## Запуск
```bash
dotnet run --project UserApi
